# design-taste — sources

## Based on

- **`design-taste-frontend`** and **`redesign-existing-projects`** from
  [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT).
  Used in five of the user's projects; `design-taste-frontend` was the most
  read third-party design skill. Taken over, restated in our own words: the
  brief-first "design read", the redesign protocol (classify, audit,
  ordered levers, never change silently), the hero and layout heuristics,
  and much of the generic-pattern list.
- **The user's own design feedback, Sep–Nov 2026**, across two dashboard
  apps, the company website and the client sites: the feedback-reading
  table, the house taste summary, the user-flagged "AI-generated" patterns,
  the show-don't-describe process, and identity from the business.

## Dropped from the upstream skills

The parts that conflict with the user's decisions:

- invented realistic names and numbers
- placeholder image and logo CDNs
- the advice to replace Lucide
- tinted shadows
- scroll reveals that render content hidden in server HTML
- the blanket em-dash ban, which doesn't fit German typography
- dashboards declared out of scope

Also dropped: the aesthetic-specific sibling skills of the same collection
(minimalist, brutalist, high-end, "gpt-taste", Stitch), which were installed
but barely used. In October 2026 the user approved removing them as
conflicting.

Not used at all: the `impeccable` skill (Apache-2.0). The user removed it in
October 2026 ("remove all impeccable references"); its process and artefacts
must not be reintroduced.
