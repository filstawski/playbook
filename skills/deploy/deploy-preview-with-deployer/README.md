# deploy-preview-with-deployer — sources

Written from:

- the user's own [`filstawski/deployer`](https://github.com/filstawski/deployer)
  repository: README, docs, examples, and its agent skill
  (`skills/deployer/`);
- the sessions in which Deployer was built and used, October 2026;
- preview deployments of the company website and of three client sites built
  from the website template.

No third-party skill was used. Deployer's own skill stays in the Deployer
repository on purpose, because it has to change together with the CLI. This
skill is the workflow around it, and defers to it for command details.
