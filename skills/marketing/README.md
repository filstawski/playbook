# marketing

Words and visibility for public sites: the copy visitors read, and whether
search engines find the page in the first place. Written for
small-business marketing sites built with Next.js, mostly German and local.

- **[marketing-copywriting](marketing-copywriting/SKILL.md)** — write,
  rewrite or audit visitor-facing copy. Diagnose the input, build from
  sourced facts, test every line, remove AI tells, and follow German voice
  and typography.
- **[marketing-seo-audit](marketing-seo-audit/SKILL.md)** — audit and fix
  search visibility: indexing, technical baseline, titles and descriptions,
  content, truthful structured data, local SEO, bilingual setups, and the
  post-launch rankings push.

## How these relate

They share one rule: nothing untrue. A title is copy that also has to work
in search results, so title and description wording follows the SEO skill
while voice and claims follow the copy skill. Both read the project's
concept doc as their brief. Both are rebuilt from
`coreyhaines31/marketingskills` (MIT); see each skill's README.
