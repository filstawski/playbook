## Know these first

- **Default to the quietest variant.** "Decent" means understated, and
  "too much" means halve it.
- **Flat is rejected, from the first version.** When an element "doesn't
  fit", give it material; don't delete it.
- **Every colour has one meaning.** The brand colour is never decoration,
  and shadows are never coloured.
- **Radius scales with size and nests concentrically;** keep it small.
- **New pages copy the existing pages' structure,** row for row.
- **Nothing untrue** on a site, and nothing that reads as AI-generated.
